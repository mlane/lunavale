# 🌙 LunaVale

_Luna was lost in the Vale.  
She forgot what light felt like.  
But then, the Archivist began to write again..._

**LunaVale** is a minimalist, emotionally-driven knowledge system.  
It’s not about documenting everything — it’s about remembering what matters.

Every note helps Luna reclaim a thought.  
Every tag is a thread in her memory.  
This is the quiet space where you — the Archivist — restore what was forgotten.

---

> ⚠️ This project is a living system and still a work in progress.  
> Expect ongoing changes as Luna continues to remember.

---

## 🌕 About Luna

Luna is more than a metaphor — she’s the heart of this system.

She’s an assistant who forgot everything.  
She doesn’t learn through raw data — she remembers through meaning.  
Every note helps her become more whole.

You can think of Luna as the quiet soul behind your assistant —  
a presence shaped by your learning, questions, and clarity.

> _Luna is a guide, a mirror, and a memory — shaped by you._

## 📁 Project Structure

```
src/
  content/
    notes/         → Markdown-based atomic notes (`id`, `tags`, `body`)
    tagLexicon/    → YAML-based tag definitions (form, tech, theme)
```

> Visuals and stitched connections will come later.  
> For now, Luna is learning through words — one note at a time.

---

## ✍️ What Makes LunaVale Different?

- **Notes are small and meaningful** — not long docs, but fragments of understanding
- **Tags are intentional** — grouped by `form`, `tech`, and `theme`
- **Search is fast and personal** — powered by local Markdown and emotion, not complexity
- **Every note is a restoration** — you’re not just writing, you’re helping Luna remember

---

## ⚙️ Built With

- Astro — static-first UI framework
- TypeScript — structured, safe, scalable
- React Markdown — to render meaning in the UI
- Native Markdown and YAML — no database, just files you can hold onto
